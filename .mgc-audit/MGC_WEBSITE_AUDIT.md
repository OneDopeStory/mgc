# MGC Global Consulting: Website Audit

- **Audit date:** 2026-09-30
- **Scope:** public main domain https://mgcglobalconsulting.com (the `www` host redirects here)
- **Performed by:** Claude Code (Opus 5.5), lead agent only. No helper agents were used, to limit cost.
- **Authorization:** research, evidence and documentation only. No site code, configuration, deploys, form submissions or payments were touched.
- **Evidence:** `.mgc-audit/evidence/crawl-manifest.json` and `.mgc-audit/evidence/lh-summary.json`. The index is `.mgc-audit/evidence/EVIDENCE_INDEX.md`.
- **Business facts:** `.mgc-audit/MGC_BUSINESS_CONTEXT.md`

---

## 1. Executive summary

The site presents a clear services-and-pricing offer with a strong visual identity. Five problems undermine trust and reach:

1. **Wrong phone number everywhere.** Every live page shows 410-952-2846. The confirmed office line, 443.208.8178, appears nowhere. The local working copy still has the old number too.
2. **Internal files are public.** The site publishes its whole repository root. Anyone can read `CLAUDE.md`, `README.md`, the SQL schemas, deploy scripts, Zapier and Slack configurations, and more. No secret keys were detected, but this is a professionalism and security exposure.
3. **Broken trust pages.** About, Privacy and Terms return 404. The 403, 404 and success pages come from a different "directory/membership" product: "Listing Not Found", "Join $27/mo", and links to `/directory`, `/members` and `/support`, all of which are 404.
4. **Very slow on mobile.** The homepage scored Performance 28, LCP 76.4 s and 71 MB transferred in a Lighthouse mobile lab run. The causes are two autoplay videos (21 MB and 25 MB) and 3–9 MB images. Desktop on a fast connection scored 95.
5. **Thin founder credibility, unsupported claims.** Mark Cartwright is named once on the site (the membership page). There is no About page, no genuine case study and no testimonial. Headline claims ("47+ automations deployed", "23 hrs saved per client per week", "Zapier Certified") have no supporting evidence on the site.

Fixing items 1–3 is mostly small, contained edits. Item 2 needs one Netlify configuration change, which requires your approval to deploy.

### F-02: Repository internals publicly served (Critical, High confidence)

- **URLs that return 200:**
  - `/CLAUDE.md`, `/AGENTS.md`, `/README.md`, `/DESIGN.md`, `/BRANDING.md`
  - `/docs/claude_usage_limits.md`, `/2026-04-07.md`

  - `/api/**`: README, deployment guide, `config/mgc-config.js`, `webhooks/server.js`, `zapier-configs/all-zaps.yaml`, the Slack master prompt, the TAIC Slack Hub page
- **Evidence:**

  - A pattern scan of these files found **no** Stripe/Slack/Notion/AWS secret keys or service-role tokens. It did find Supabase project refs and anon keys, which are public by design.

### F-05: Mobile homepage performance (High, High confidence for lab)

- **URL:** `/`
- **Evidence (Lighthouse 12.8.2, 2026-09-30):**

  | Run | Performance | LCP | TBT | Page weight |
  |---|---:|---:|---:|---:|
  | Mobile | 28 | 76.4 s | 7,270 ms | 71,413 KiB |
  | Desktop | 95 | 1.1 s | — | same payload |

- **Largest files:**
  - Videos: `m-one-shot.mp4` 24.9 MB and `globe-connected.mp4` 21.4 MB, both autoplaying on Vercel Blob.
  - Images: `earn-commission.jpeg` 9.2 MB, `get-paid-image.png` 5.8 MB, `unify-1.png` 5.4 MB, `mgc-logo-transparent.png` 3.2 MB (used as a roughly 40 px logo).
  - Lighthouse estimates about 24 MB of image savings.
- **Visitor impact:** on phones and metered connections the page appears blank or slow for a long time. Many visitors will leave before the offer loads, and it consumes their data.
- **Fix:**
  - Do not autoplay video on mobile. Use `preload="none"`, a lightweight WebP/AVIF poster, and play on tap or when the video is visible on desktop.
  - Re-encode videos to 720p H.264 plus WebM at about 1.5–3 MB each.
  - Convert images to WebP/AVIF at display size with `srcset`, `width`/`height` and `loading="lazy"` below the fold.
  - Export the logo at 2× display size (under 30 KB).
- **Effort:** M
- **Acceptance check:** Lighthouse mobile shows Performance ≥ 80, LCP ≤ 2.5 s and total weight ≤ 3 MB.

## 5. Firebase suitability assessment

- **Is Firebase used?** No. There is no `firebase.json` or `.firebaserc` and no code references. The Firebase MCP reports no project and no authenticated user.
- **Account-level checks:** unverified, because Firebase login is unavailable in this session.
- **Current stack coverage:**

  | Need | Current service |
  |---|---|
  | Hosting and CDN | Netlify |
  | Serverless functions | Netlify Functions |
  | Authentication and database | Supabase (email/password, Google OAuth, RLS) |
  | Payments | Stripe |
  | CRM | Notion |

- **Possible Firebase additions, compared with the current stack:**

  | Firebase product | What it would replace or add | Cost (official pricing, checked 2026-09-30) | Assessment |
  |---|---|---|---|
  | Hosting | Netlify | Spark plan: 10 GB storage, 360 MB/day transfer. On Blaze: $0.026/GB storage over 10 GB, $0.15/GB transfer over the free tier | **Not recommended.** It duplicates Netlify and would require moving the functions. At today's 71 MB mobile homepage, the free daily transfer covers about 5 visits. |
  | Authentication | Supabase Auth | 50K monthly active users free (Identity Platform tier) | **Not recommended.** It duplicates Supabase Auth and would split user data across two vendors. |
  | Firestore / Storage | Supabase DB and Storage | Free tiers exist | **Not recommended.** It creates a second database to secure and maintain. |
  | App Check (reCAPTCHA Enterprise for web) | Bot protection | reCAPTCHA Enterprise has its own quota | **Only partly relevant.** App Check protects Firebase and Google Cloud backends, not Netlify Functions. For form spam, a honeypot (already used in `/api/index.html`) or Netlify's built-in spam filtering is simpler. |

- **Privacy and maintenance:** each added vendor means another data processor to disclose in the privacy policy, another console to secure, and another bill.
- **Verdict:** do not add Firebase. The existing Netlify, Supabase and Stripe stack covers the site's needs at lower complexity. Revisit only for a native mobile app, where Firebase Cloud Messaging or Crashlytics add distinct value.
